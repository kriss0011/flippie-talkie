# Security and transmit safety

Report these privately through [a GitHub security advisory](https://github.com/kriss0011/flippie-talkie/security/advisories/new), not a public issue:

- anything that lets a remote page or nearby device control the radio without the user's action
- a transmitter that fails to stop: a bypass of the audio timeout, the contact timeout or the 60-second limit
- a bypass of the firmware's transmit-frequency check
- exposure of recordings or audio outside the user's own browser and Flipper

Include the app, web and firmware versions, and the steps to reproduce. Only the latest release gets fixes.

This is a hobby project, so replies may take a few days. Please allow time for a fix before publishing details.
